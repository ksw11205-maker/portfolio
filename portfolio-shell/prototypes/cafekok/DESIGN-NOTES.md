# CAFÉKOK 디자인 방향 — 조용히 둘러보는 카페 큐레이션

작성일: 2026-10-29

## 이번 작업의 기준

사용자가 참고 사이트 선택을 맡기고, 차분한 카페 추천 앱으로 화면 구성을 수정하도록 요청했다. 특정 작가의 화면을 복제하는 작업이 아니라, 카페 공간을 발견하고 비교하는 데 맞는 자체 디자인이다. 제목과 카드 문구는 왼쪽 정렬한다. 사용자 요청에 따라 사진과 카드 본문 사이에 틈을 두지 않으며, 호버와 선택 상태는 테두리 대신 면 색으로 구별한다.

## 확인한 1차 자료와 가져올 원칙

### Kinfolk — Ten Cafés in Seoul

출처: https://www.kinfolk.com/stories/ten-cafes-in-seoul/

접근 가능한 본문에서 여러 카페를 하나의 큐레이션으로 묶고, 각 공간의 빛·건축·재료·좌석·동네에 관한 설명과 주소를 함께 제공하는 구성을 확인했다. 본문에는 공간 사진 링크와 사진 설명이 여러 지점에 포함되어 있다.

카페콕에서는 사진을 먼저 보고, 카페 이름과 한 줄의 분위기 설명을 읽은 다음, 지역·가격과 취향 일치도를 확인하도록 정보 순서를 정리한다. 취향과 잘 맞는 추천과 다른 분위기를 발견하는 추천을 구별한다. 특정 카페의 소개 문장이나 사진을 가져오지 않는다.

### STAYFOLIO — 홈과 Journal

출처: https://www.stayfolio.com/en

보조 페이지: https://www.stayfolio.com/en/journal/magazines

접근 가능한 페이지에서 장소 탐색인 FIND STAY와 편집 콘텐츠인 JOURNAL을 분리하고, 홈·탐색·북마크 등의 이동 항목을 제공하는 구조를 확인했다. Journal에는 Magazine과 Pick 구분이 있다. 이 정보 구조를 참고해 카페콕의 홈은 큐레이션, 탐색은 조건별 비교, 저장은 다시 찾을 장소, 내 취향은 추천 기준을 관리하는 화면으로 역할을 분명히 한다.

## 확인 범위와 한계

위 자료는 웹 도구가 제공한 본문, 링크, 이미지 대체 설명으로 확인했다. 실제 렌더링 화면과 CSS를 캡처하거나 측정하지 못했다. 따라서 아래 색상값, 정렬, 여백, 글자 크기, 카드 비율은 해당 사이트의 공식 디자인 가이드에서 추출한 값이 아닌 카페콕을 위한 제안이다.

앞서 요청한 Dribbble 작품과 같은 작가의 다른 커피 앱도 확인을 시도했다. 작품과 이미지 URL은 확인했지만 웹 도구가 이미지 픽셀을 전달하지 않았고 이미지 다운로드도 HTTP 403으로 실패했다. 그 작품의 카드·메뉴바를 시각적으로 분석했다고 주장하지 않는다.

## 카페콕의 디자인 규칙

- **색:** 따뜻한 아이보리 배경, 낮은 채도의 토프 보조 면, 차콜 본문. 진한 색은 주요 버튼과 현재 선택한 항목에 한정한다. 과한 그라데이션과 색 블록은 줄인다.
- **정렬:** 화면 제목, 섹션 제목, 카드 이름·설명·메타데이터를 왼쪽에 맞춘다. 사용자가 정정한 요청에 따라 왼쪽 정렬을 기본값으로 사용하고, 메뉴와 짧은 버튼의 내부 레이블은 중앙에 둔다.
- **글자:** Pretendard 한 계열을 유지한다. 주요 제목 24–28px, 본문 15–16px, 보조 정보 12–13px를 기준으로 위계를 만든다. 문장 중 특정 단어에 별도 강조 글씨체를 적용하지 않는다.
- **사진과 카드:** 사진은 카드 상단을 끝까지 채우고 본문과 바로 이어지게 한다. 일정한 사진 비율과 본문 패딩을 적용해 카드별 정보 밀도를 맞춘다. 기존 30개 가상 카페의 서로 다른 대표 이미지 대응을 유지한다.
- **호버·선택:** 카드와 칩은 배경 면 색 변화로 상태를 드러낸다. 호버용 테두리, 선택용 테두리와 과한 이동 효과는 쓰지 않는다.
- **키보드 포커스:** 호버·선택 상태와 별개로 `:focus-visible` 표시를 유지한다. 테두리 없는 시각 스타일 때문에 키보드 사용자의 현재 위치까지 없애지 않는다.
- **메뉴바:** 하단 이동 항목의 아이콘은 20px 기준으로 크기와 선 굵기를 통일한다. 활성 메뉴는 배경 면과 글자 색으로 식별하고 터치 영역은 아이콘보다 넉넉하게 둔다.
- **정보 순서:** 사진 → 카페 이름 → 지역·가격 → 짧은 추천 이유. 취향 일치 표시는 사진 안에서 작은 크기로 유지한다.
- **움직임:** 기존 사진 자동 교체와 화면 전환을 부드럽게 유지하며 `prefers-reduced-motion` 설정을 존중한다. 불필요한 전환 제어 버튼을 추가하지 않는다.
- **기능:** 취향별 추천, 가로 카드 스크롤, 검색·저장·개별 취향 수정과 기존 알림 흐름을 보존한다.

## 이미지와 출처

참고 사이트의 로고, 독자적인 그래픽, 사진이나 문구를 앱 자산으로 복사하지 않는다. 기존 카페 이미지의 출처 관리는 ASSET-SOURCES.md를 따른다. 가상 카페의 사진과 위치·가격 데이터는 실제 업소를 검증한 정보가 아니다.

## 후속 수정

첫 접속 화면의 커버는 상단과 양옆 여백 및 모서리 곡률 없이 앱 너비를 채우고 높이를 52dvh로 늘렸다. 로고와 본문, 헤더와 팝업도 왼쪽 기준선으로 정렬했다.

## 2026-11-02 — 메모 반영

- 본문 배경과 카드 기본 면은 흰색으로 통일하고, 공통 헤더·퀴즈 헤더·상세 상단에만 은은한 커피색을 적용했다. 선택/호버 면은 중성 회색으로 유지한다.
- 퀴즈 완료 여부를 브라우저 저장 상태에 기록한다. 완료 후 공통 헤더와 퀴즈의 로고는 홈으로 이동한다. 기존 저장 데이터는 유효한 여섯 응답이 있으면 완료 상태로 이어받는다.
- 퀴즈 하단은 이전/다음 두 버튼이다. 마지막 단계는 '내 취향 보기'로 완료한다. 이전 이동 시 응답을 보존한다.
- 별도 무드보드를 제거하고 취향 요약 안에 키워드별 사진을 넣었다. 6초 간격, 1.2초 페이드 전환이며 동작 축소 설정을 존중한다. 무료 사진 출처는 ASSET-SOURCES.md와 설정 화면에 기록한다.
- 홈 사진은 좌우 여백 없이 채우며 제목과 설명을 사진 위에 배치한다.
- 일치율 배지는 사진 왼쪽 위의 원형 퍼센트다. 75% 이상 말차, 40–74% 귀리 우유, 40% 미만 블루 그레이로 구별한다. 계산 기준이 없는 경우 배지를 숨긴다. 배지 색은 사용자가 별도로 요청한 본문 색상 예외다.

## 후속 대비 조정

사용자 주석에 따라 헤더를 에스프레소색과 밝은 로고로 변경했다. 카드에는 은은한 그림자를, 방문 목적 버튼에는 항상 같은 얇은 테두리를 적용했다. 호버/선택은 계속 면 색으로 표시한다. 홈 취향 안내 박스는 연한 커피색과 14px 곡률을 사용한다. 일치율 배지는 각 색상을 진하게 조정하고 흰 글자를 쓴다.

## 현재 위치와 추천 목록 탐색

- 헤더의 지역 선택을 '현재 위치로 설정' 버튼으로 교체했다. 클릭 시 브라우저 위치 권한을 사용하며 정확한 좌표는 저장하거나 서버로 전송하지 않는다. 부산 샘플 지역 중심의 10km 이내에서는 가장 가까운 데이터셋을 선택하고, 그 밖에서는 샘플 지역 밖이라는 안내와 함께 기존 부산 가상 카페를 보여준다. 위치 거부·실패·시간 초과를 화면에서 안내한다.
- 취향 추천과 다른 분위기 추천 모두 마우스 드래그, 터치 스크롤, 방향키 탐색이 가능한 가로 목록으로 통일했다. 드래그 뒤 상세/저장 클릭은 막고, 일반 클릭은 유지한다.
- 홈 제목은 '카페 방문 목적', '취향 일치순 추천'(취향 없으면 '추천 카페'), '다른 분위기의 카페', '내 카페 취향 설정'으로 정리하고 설명 문구를 제거했다. 탐색/저장 페이지 제목은 '카페 탐색', '저장한 카페'다.

## 새 방문 초기화

사용자 정정에 따라 취향·퀴즈 완료·저장 목록·목적·지역을 브라우저에 저장하거나 복원하지 않는다. 기존 cafekok-state 키는 시작 시 정리하고, 매 새로고침/방문 시 시작 버튼은 빈 퀴즈로 이동한다. 현재 이용 중 퀴즈 완료 후 로고를 누르면 홈으로 이동한다. 저장 목록의 빈 안내 영역에는 연한 커피색과 14px 곡률을 적용했다.

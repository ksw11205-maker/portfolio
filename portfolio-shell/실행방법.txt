김성원 포트폴리오 실행 방법

1. 압축을 풀고 VS Code에서 압축을 푼 폴더를 엽니다.
2. VS Code 메뉴에서 터미널 > 새 터미널을 선택합니다.
3. 아래 명령을 입력합니다.

   Windows:  py -m http.server 8000 --directory dist
   macOS:    python3 -m http.server 8000 --directory dist

4. 브라우저에서 http://localhost:8000/ 을 엽니다.
5. 종료하려면 터미널에서 Ctrl+C를 누릅니다.

Python이 설치되어 있어야 합니다. 설치가 안 되어 있다면 python.org에서 Python을 설치하세요.
직접 HTML 파일을 더블 클릭하지 말고 위의 로컬 서버 주소로 접속하세요.
사이트 파일은 dist 폴더 안에 있습니다. LG 상세페이지는 dist/work/lg/ 에 있습니다.
이 압축본은 현재 배포된 정적 사이트와 프로토타입 실행 파일입니다.

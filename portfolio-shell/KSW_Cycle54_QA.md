# KSW 54 — IVI desktop evidence gallery

## 변경
- `dist/work/ivi/editorial.css`: 1200px 이상 연구 아카이브의 5열 소형 썸네일을 3열 큰 원본 UI 캡처 중심 에디토리얼 그리드로 전환. 이미지와 캡션 15개, 내용, 쉘, CTA, 링크는 변경하지 않음.
- 701–1199px 3열, 601–700px 2열, 600px 이하 가로 스와이프는 기존 53차 규칙 유지.
- 원본 53차 ZIP은 별도 보존, main/Netlify 미수정.

## 검증
- CSS 구문 및 원본 이미지 파일 존재는 정적 검토 대상.
- 실제 Chromium Playwright 시도: `net::ERR_BLOCKED_BY_ADMINISTRATOR` (127.0.0.1 로컬 서버 접근 차단). 실브라우저 렌더/스크린샷 **미검증**.
- Before/After **비교 이미지 미생성**. 가짜 이미지 없음.
- 고정 한국 디자이너 레퍼런스의 링크/국적/게시일 이번 회차 재검증하지 않음. 기존 LG 고정 3개 유지, IVI 고정 목록의 확정 여부는 manifest 실물 재검증 필요.
- GitHub 및 Netlify 최신 소스 차이도 이번 회차 재검증하지 못함.

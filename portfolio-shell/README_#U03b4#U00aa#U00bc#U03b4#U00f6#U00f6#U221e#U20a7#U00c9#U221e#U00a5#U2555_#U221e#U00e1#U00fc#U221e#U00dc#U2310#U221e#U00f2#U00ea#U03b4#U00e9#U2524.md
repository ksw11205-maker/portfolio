# KSW 에디토리얼 리디자인 Pass 01

## 실행 / Netlify 업로드
1. 압축을 해제합니다.
2. Netlify Drop에서 `portfolio-vscode/dist` 폴더 **자체**를 새 사이트로 드래그하여 업로드합니다.
3. 로컬에서는 `portfolio-vscode` 폴더에서 다음 명령으로 시작합니다.
   `py -m http.server 5500 --directory dist`
   브라우저 주소: http://localhost:5500/
4. 기존 Netlify 사이트는 자동 갱신되지 않습니다. 별도 미리보기 사이트에 먼저 올려 검수한 뒤 전환하세요.

# KSW 47 — IVI 모바일 리서치 아카이브 가독성

- 기준: 46차 누적 ZIP. 기존 15개 차량 인터페이스 스크린샷 및 연구 문구 유지.
- 결함: 600px 이하에서 15개 참고 화면을 2열 그리드로 표시하여 390px 화면에서는 이미지와 캡션이 작아짐.
- 수정: `dist/work/ivi/editorial.css`에서 모바일 아카이브를 가로 스크롤·스냅 방식으로 재배치. `dist/work/ivi/index.html`에서 스크롤 컨테이너에 `tabindex=0`, `role=region`, `aria-label`을 부여해 키보드 탐색 지원. 아카이브는 기존 `<details>` 안에 유지.
- 보존: 프로젝트의 15개 원본 이미지, 4종 실험 비교, 최종 설계 제안, 쉘, CTA 및 모든 다른 파일.
- 레퍼런스: 기존 고정 레퍼런스 목록을 변경하거나 새로 확정하지 않음. 이번 변경은 작은 화면에서 원본 자료의 가독성을 확보하는 자체 UI QA 개선.
- 검증: ZIP CRC 검사 및 변경 파일 범위 확인. 실브라우저 1440/1280/768/390 QA 미실시. Before/After 비교 이미지 미생성(실제 렌더 촬영 미실시).
- GitHub main / Netlify: 미변경.
- 다음 우선순위: LG 실브라우저 검증 및 IVI 전체 상세페이지 시각적 검수.

THE CONTEXT

멀리서 조작하는 화면. 더 명확한 판단 기준이 필요했습니다.

콘텐츠와 기능이 한 화면에 쌓이는 TV. 화면에서 떨어진 사용자는 리모컨으로 항목을 탐색하고, 원하는 기능을 선택해야 합니다.

이 프로젝트는 TV UI 요소가 사용성에 미치는 영향을 실험으로 살피고, 그 결과를 디자인 의사결정에 활용하는 도구의 UI로 구체화했습니다.

MY CONTRIBUTION

대표 시퀀스 선정, 실험과 예측 모델 개발은 연구팀의 공동 작업입니다. 저는 요구사항에 맞춘 AI Design Tool UI 프로토타입 제작·수정, 보고와 검토를 위한 자료·이미지 조사 및 시각 자료 구성에 참여했습니다.

화면을 보기 전에, 사용자의 목적부터 좁혔습니다.

검색·시청·제어의 목적에서 대표 시퀀스를 정리하고, 비교할 수 있는 화면과 사용성 요인을 정의했습니다.

  2. 02

    사용성 요인 선별

    문헌·가이드라인과 실제 UI에서 측정할 변수를 정리

  3. 03

    실험과 모델 개발

    주요 요인의 영향과 사용성 예측 모델을 연구팀이 분석

  4. 04

    입력·분석·대안·비교의 흐름을 프로토타입으로 구체화

THE DESIGN CONNECTION

모델의 숫자를 사용자가 다룰 수 있는 입력과 판단으로.

탐색형의 썸네일 항목 수, 설정·조작형의 텍스트·아이콘 크기처럼 주요 요인을 화면에서 확인하고 조정하도록 연결했습니다. 점수를 제시하는 것에 더해, 무엇을 검토하고 바꿀 수 있는지 보이게 하는 데 초점을 두었습니다.

04 / AI DESIGN TOOL

하나의 작업이, 다음 판단으로 이어지도록.

API 연결 → 화면 입력 → 분석 → 대안 → 비교. 사용 순서대로 화면을 확인합니다.

  1. API KEY
  2. UPLOAD
  3. ANALYZE
  4. RECOMMEND
  5. COMPARE
START / API KEY

처음 실행하면, API KEY부터 입력합니다.

발급받은 키를 입력하고 연결한 뒤 TV 화면 평가를 시작합니다.

BEFORE UPLOAD

분석하기 전에, 평가할 화면부터 입력합니다.

평가 유형을 선택하고 TV 화면 이미지를 불러오는 시작 상태입니다.

01 / INPUT

평가할 화면과 요인값을 먼저 확인합니다.

TV UI를 입력한 뒤 평가 유형을 선택하고 화면 요소의 값을 검토·조정합니다.

02 / ANALYZE

점수 뒤의 영향 요인을 읽습니다.

점수·등급과 함께 요인별 영향을 보여주어, 무엇부터 검토할지 판단하도록 구성했습니다.

03 / RECOMMEND

바꿀 요인을 선택하고, 권장안을 검토합니다.

사용자가 조정하는 영역과 AI 권장 패널을 구분해, 대안 생성의 입력과 제안을 함께 확인하게 했습니다.

04 / COMPARE

기존 화면과 대안을, 같은 기준으로 비교합니다.

As-Is / To-Be UI와 요인값·예측 점수의 차이를 나란히 읽도록 구성했습니다.

BEYOND THE MAIN FLOW

작업을 이어가는 환경도 한곳에서 확인하도록.

작업 이력과 API 연결, 모델·평가 기준, 저장·보안 옵션을 별도의 설정 구조로 정리했습니다.

05 / REFLECTION

화면의 이유를, 설명할 수 있는 디자이너로.

Q01

무엇을 배웠나요?

A.

LG전자 UI/UX 부서와 소통하는 산학 연구에 참여하며, 실험과 분석의 결과가 도구 화면으로 구체화되는 과정을 경험했습니다. 학부연구생으로서 요구사항을 프로토타입으로 옮기고 중간 검토와 피드백을 반영했습니다. 시각적 완성도만큼 판단 근거를 짧고 명확하게 공유하는 일이 중요함을 배웠습니다.

Q02

무엇이 아쉬웠나요?

A.

복잡한 연구 내용을 이해하면서 짧은 일정에 맞춰 결과물을 정리해야 했습니다. 화면을 만드는 작업에 집중한 만큼, 연구의 맥락과 작업 목적을 더 일찍 구조화했다면 피드백을 받아들이고 대안을 설명하는 데 도움이 되었을 것입니다.

Q03

다음에는 어떻게 바꾸고 싶나요?

A.

작업 시작 단계에서 목적과 완료 기준을 정리하고, 이해가 부족한 부분을 적극적으로 확인하려 합니다. 요청된 디자인안을 만드는 데서 나아가 연구의 근거와 연결되는 대안을 스스로 설명하고 제안하는 역량을 넓히고 싶습니다.

# CAFÉKOK 작업 공간

기존 초안을 발전시킨 포트폴리오 케이스 스터디의 편집 원본과 자료를 보관합니다.
실제 카페 검색·인증·지도 API·추천 서버를 구현하는 앱은 아닙니다.

- 편집 원본: [cafekok-detail/cafekok/](cafekok-detail/cafekok/)
- 실행: 저장소 루트에서 `node portfolio-shell/server.cjs`
- 상세: http://localhost:4173/work/cafekok/
- 메인: http://localhost:4173/
- 배포 복사: `node portfolio-shell/build.cjs`
- 생성 결과: `portfolio-shell/dist/work/cafekok/` — 직접 편집하지 않습니다.

HTML/CSS/JavaScript와 Node 내장 모듈만 사용하며 패키지 설치가 필요하지 않습니다.
단일 편집 원본을 기존 포트폴리오의 정적 배포 폴더로 복사합니다.
원본 편집 후 빌드를 다시 실행하거나 서버를 재시작합니다.

[프로젝트 문서](../docs/projects/cafekok.md)에서 콘텐츠·자료 상태·제안 정책·미확정 사항을 관리합니다.
[공통 디자인 기준](../DESIGN.md)과 [작업 지침](../AGENTS.md)을 따릅니다.
`assets/brand/`, `assets/screens/`, `assets/research/`는 추가 원자료의 준비 위치이며
현재 상세에 사용하는 사진·폰트는 기존 초안의 `cafekok-detail/cafekok/assets/`에 보존했습니다.

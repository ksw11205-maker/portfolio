사진위치후기

같은 카페도,
누구와 무엇을 하느냐에 따라.

공부, 데이트, 대화, 드라이브. 방문 목적은 달라지고 좋아하는 분위기와 좌석, 메뉴, 가격, 이동 거리도 사람마다 다릅니다. 카페콕은 이 기준들을 연결해 탐색과 비교의 부담을 줄이고자 기획했습니다.

04 / USER CONTEXT

필요한 자리가 다르면,
먼저 보고 싶은 정보도 다릅니다.

사용자 유형과 여정은 설계 가설입니다.
방문 목적에 따른 정보 요구를 비교했습니다.

A / 공부·작업

혼자 집중할 곳을 찾는 대학생

수업 뒤, 과제를 이어갈 카페를 찾는 상황.

원하는 경험
무리 없이 머물며 집중하기
판단 기준
분위기 · 좌석 · 가격 · 이동 거리
핵심 불편
사진만으로 작업하기 편한 자리를 알기 어려움
필요한 도움
좌석과 이용 조건을 후보별로 함께 확인
  1. 방문 계기과제를 할 자리가 필요하다
  2. 탐색갈 수 있는 거리에서 후보를 찾는다
  3. 비교좌석과 가격을 같은 기준으로 본다
  4. 선택작업 조건이 확인된 곳을 고른다
  5. 방문실제 좌석과 분위기를 확인한다

B / 친구와 대화

편하게 만날 곳을 찾는 직장인

  3. 비교함께 앉을 좌석과 메뉴를 본다
  4. 선택만남에 맞는 이유를 보고 결정한다

추천 결과가 없으면

적용된 조건을 보여주고 이동반경이나 가격 범위를 하나씩 조정하게 합니다. 사용자의 동의 없이 조건을 바꾸지 않습니다.

로그인하지 않았다면

취향 입력·탐색·상세 확인과 기기 내 저장까지 가능합니다. 기기 간 취향·저장 목록을 동기화할 때만 계정을 제안합니다.

09 / VALIDATION PLAN

설명한 이유가,
실제 선택에도 도움이 될까?

사용성 검증은 아직 수행하지 않았습니다.
대표 과제를 수행하며 행동과 망설임,
추가로 필요한 정보를 관찰할 계획입니다.

  1. 01

    취향 질문과 결과를 이해할 수 있는가?

    취향 입력 후 결과를 설명하고 수정하는 과제에서 질문 해석과 망설이는 지점을 관찰합니다.

  2. 02

    방문 목적에 맞는 후보를 찾을 수 있는가?

    작업 또는 대화할 곳을 찾는 과제에서 확인하는 정보와 조건 변경 과정을 살펴봅니다.

  3. 03

    추천 이유가 최종 선택에 도움이 되는가?

    후보를 비교하고 한 곳을 고른 뒤, 선택 근거와 추가로 확인하고 싶은 정보를 듣습니다.

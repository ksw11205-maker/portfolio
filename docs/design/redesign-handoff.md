## 사용자의 현재 승인 범위
현재 버전을 GitHub에 보관하고, 기존 내용만 추출하고, 새 디자인에 필요한 폰트·아이콘·모션·스크롤·버튼·호버 등을 조사·준비하는 작업.
실제 새 디자인 구현, 개발 서버 실행, 브라우저 실행, 배포는 아직 하지 않았다. 모델 변경은 사용자가 선택한다.

## 다음 구현 프롬프트
기존 코드의 외형을 수정하는 방식이 아니라 새 공통 디자인 기준을 따르는 별도 구현을 만든다.
내용은 content-snapshot의 출처를 사용하고 수치·역할·연구 결과·미검증 상태를 유지한다.
메인과 IVI 상세 하나를 먼저 완성해 시각 방향과 설명 구조의 기준으로 삼는다.
페이지마다 타이포와 간격은 통일하되 프로젝트 성격과 화면 배열에는 강약을 둔다.
도구 나열, 의미 없는 카드, 전면 스크롤 제어를 기본 구성으로 삼지 않는다.
브랜드 인상과 실제 화면, 설계 근거의 관계를 보여준다.
이후 별도 구현 승인을 받으면 디자인 제안→실제 구현→화면 검수 순으로 진행한다. 이전 사용자 요청만으로 배포하거나 원본 보관 브랜치를 수정하지 않는다.

## 확인할 콘텐츠
- 정확한 개인 기여·팀 구성·기간은 현재 페이지 표기와 원자료를 구분해 확인.
- LG의 65.81/79.20은 모델 설명력이며 개선율·정확도로 바꾸지 않기.
- IVI 4개 실험 유형, 미검증 하이브리드 제안, 지도 갱신 이후 캡처를 구분.
- CAFÉKOK/OFFER의 데모·계획을 실제 서비스 성과로 바꾸지 않기.
- 과거 GitHub 프로젝트 문서의 '미확정'과 최신 페이지의 표시가 충돌할 경우 임의 통합하지 않고 출처와 확인 필요를 기록.

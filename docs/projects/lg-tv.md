# LG TV

공통 기준은 [DESIGN.md](../../DESIGN.md)를 따른다. 이 문서는 LG TV의 콘텐츠와 디자인 차이만 기록한다.

## 연결과 표지

- 상세 경로: /work/lg/. 메인 LG 카드 이미지와 상세 링크가 이 경로로 이동한다. 상단·하단의 복귀 링크는 /#work이다.
- 승인된 마젠타·바이올렛 거실 목업을 메인 표지와 상세 히어로에서 재사용한다. 노트북은 AI Design Tool, TV는 평가 대상 화면이다. 목업과 본문 실제 프로토타입 캡처를 구분한다.
- 기존 메인 쉘·내비게이션·다른 프로젝트는 변경하지 않는다. 공통 page-transitions.css/js를 그대로 재사용한다.
- 800px 이하에서는 목업 전체를 먼저 보여주고 그 아래에 소개를 배치해 두 기기가 잘리지 않게 한다.

## 구현과 원본

- 디자인 기준: Figma lmP0Ar9RfHciiN22KNxClC, LG 01–14 연속 스크롤 배경 섹션 719:584. 원본 디자인과 별도 복제본은 변경하지 않는다.
- 편집 소스: portfolio-shell/dist/work/lg/index.html, styles.css, script.js 및 assets/.
- 텍스트·프로세스·변수·모델·회고는 네이티브 HTML이다. 14개 data-figma-node 속성으로 디자인 원본을 추적한다. 전체 페이지를 이미지로 평탄화하지 않는다.
- TV 화면과 AI 툴 화면은 Figma의 실제 콘텐츠 자산이다. IA는 원본 노드의 SVG를 사용하고, 모바일에서는 동일한 내용을 세로 HTML 흐름으로 읽게 한다.
- 프로젝트 당시 초기 UI는 최종보고 p.24/26의 실제 화면이며, 최근 개인 UI 개선과 구분한다. 자세한 자산 근거는 assets/README.md에 기록한다.
- LG 내부에만 다크 #0B0A0E와 절제된 핑크·보라를 적용한다. 본문 전체에 걸친 공통 배경과 회고 앞의 화이트 전환을 사용한다. 장식 일러스트는 사용하지 않는다.
- Noto Sans KR 400/700, Inter 500/700을 로컬 호스팅하며 폰트 라이선스를 보존한다.

## 연구 사실과 성과 표현

- 최종보고 자료: LG전자 × 동의대학교 UXU LAB, 2025.03–09.
- 대표 시퀀스는 탐색형 이동과 설정·조작(제어)이다. 목적형을 탐색형과 통합한 과정을 설명한다.
- 1차 실험은 시퀀스별 12개씩 총 24개 조합, 실제 참여자 10명, 1–7점 사용성 평가다.
- 보고서 p.12–13의 주요 요인 표기를 적용한다. 탐색형의 가장 큰 주효과는 Thumbnail Item Count이며, 설정·조작의 두 요인은 Text Item Size와 Icon Item Size다.
- 2차 실험은 탐색형 27개, 설정·조작 9개, 총 36개 조합이다. 실제 참여자 10명과 AI 증강 데이터 10명분을 명확히 구분한다.
- 보고서 p.20의 모델 변수는 탐색형 X6 = Thumbnail Item Count, 설정·조작 X2 = Icon Item Size다.
- 65.81%와 79.20%는 수정 결정계수(모델 설명력)이며 예측 정확도나 사용성 개선율로 표현하지 않는다.
- AI 툴은 UI 프로토타입이다. 캡처의 데모 점수·대안값을 검증된 개선 성과로 주장하지 않는다.
- 보고서 원문, API 키와 민감 정보를 공개 자산에 포함하지 않는다.

## 모션과 동작

- 기존 쉘의 네이티브 페이지 전환을 재사용한다. 링크와 브라우저 히스토리를 가로채지 않는다.
- 기존 GSAP 3.13.0에 같은 버전의 ScrollTrigger를 추가한다. 제목·단계·캡처는 진입 시 한 번만 등장한다. 배경은 정적으로 이어진다.
- 각 그룹의 전체 시간차는 최대 0.32초다. 긴 목록이 연출 때문에 늦게 읽히지 않게 한다.
- 모바일 이동량 12px, 그 외 20px. prefers-reduced-motion에서는 정적 최종 상태로 노출한다.
- 캡처와 IA의 확대 모달은 원본 크기/화면 맞춤, Escape 닫기, 포커스 복귀를 지원한다.
- JavaScript가 비활성화되거나 GSAP가 없을 때도 연구 본문은 기본 상태로 모두 노출한다.

# LG TV

공통 기준은 [DESIGN.md](../../DESIGN.md)를 따른다. 이 문서는 LG TV의 콘텐츠와 디자인 차이만 기록한다.

## 연결과 표지

- 상세 경로: `/work/lg/`. 메인 카드 이미지와 상세 링크 모두 이 경로로 이동하고, 상세 상단과 하단에서 `/#work`로 돌아간다.
- 2026-10-19 사용자 승인 표지: 마젠타·바이올렛 조명의 거실, 전면 노트북과 후면 TV. 노트북에는 분석 도구, TV에는 평가 대상 화면을 재현한 목업이다. 실제 HTML 캡처가 아니며 본문 실제 UI 자료와 구분한다.
- 메인 카드에는 표지 문구 없이 1920px·960px JPG를 사용한다. 상세에는 같은 목업의 WebP와 프로젝트 소개를 배치한다.
- LG 범위만 다크 배경과 절제된 핑크 포인트를 사용한다. 메인 전체의 공통 테마는 변경하지 않는다.

## 상세 페이지 구성

사용자 지정 연구 순서를 유지한다. 배경·목표 → 대표 시퀀스 설정 → 1차 실험과 주요 요인 도출 → 2차 실험과 사용성 예측 모델 개발 → AI Design Tool 개발.

표지 포함 12개 화면 공간:
1. 표지와 프로젝트 소개
2. 연구 배경과 목표
3. 대표 시퀀스 설정
4. 1차 실험을 위한 후보 요인 선정
5. 1차 실험 설계
6. 주요 사용성 요인 도출
7. 2차 실험 설계
8. 사용성 예측 모델 개발
9. AI Design Tool 전체 흐름
10. 입력·요인 조정 UI
11. 분석·문제 진단 UI
12. 대안 생성·비교 UI

본문은 섹션 제목·짧은 개요·시각 자료 자리만 만든 초안이다. 실제 그래프·연구 결과·UI 캡처와 세부 문구는 사용자의 장별 피드백에 따라 반영한다. 빈 영역을 가상의 수치나 성과로 채우지 않는다.

## 콘텐츠 근거와 주의점

- 사용자 제공 최종보고서: LG전자 × 동의대학교 UXU LAB, 2025.03~2025.09. 연구 흐름과 상세 구성의 원자료.
- 대표 시퀀스는 탐색형 이동과 설정·조작(제어)이다. 목적형은 탐색형과 통합한 과정을 설명한다.
- 실제 참여자와 AI 증강 데이터를 구분하고, 모델 적합도를 정확도나 개선율로 표기하지 않는다.
- 업그레이드한 HTML 도구는 UI 프로토타입이다. 데모 점수와 대안값을 검증된 사용성 개선 성과로 주장하지 않는다.
- 공개 자산에 API 키나 보고서의 민감 정보를 포함하지 않는다.

구현: `portfolio-shell/dist/work/lg/{index.html,styles.css,assets/cover.webp}`. 공통 빌드 결과물에 그대로 포함된다.

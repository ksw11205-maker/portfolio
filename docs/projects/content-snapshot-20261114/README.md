# 기존 포트폴리오 내용 추출본
소스: 보관 브랜치의 portfolio-shell/dist. 추출 과정에서 사이트 JS·서버·브라우저를 실행하지 않았다. extract.cjs는 정적 파일을 읽는 데이터 처리 도구다.
- home/lg/ivi/cafekok/offer.json: 본문 블록, 전체 텍스트, 표, 이미지 경로·원본 해시, 캡션, 링크, Figma 노드.
- 같은 이름의 .md: 사람이 읽을 수 있는 본문·표 추출본.
- structured-data.json: 프로젝트 4개, Q&A 5개, 연락처, IVI 과제별 실제 표시 수치.
- extraction-report.json: 추출 개수와 참조 확인 결과.
디자인 CSS, 레이아웃 class, 모션 효과는 새 콘텐츠 모델에 복사하지 않았다. width/height는 이미지 원본 추적용 메타데이터다.
원문 그대로의 표현은 검증된 사실이라는 뜻이 아니다. sourceStatus로 현재 페이지의 주장을 보존했음을 표시한다.
이 폴더는 원문 스냅샷이며 새로운 프로젝트 사실 명세를 중복 작성하는 곳이 아니다. 프로젝트 사실 관리 기준은 상위의 프로젝트별 .md 문서다.
새 콘텐츠를 편집할 때 원본 원자료와의 차이를 확인하고, 새 순서·요약·문장 편집은 별도 레이어로 관리한다.
추출 JSON은 모든 화면 상태를 브라우저로 캡처한 결과가 아니다. JS의 known static data는 평가하지 않고 문자열에서 구조를 추출했다.

# IVI

공통 기준은 [DESIGN.md](../../DESIGN.md)를 따른다. 본 문서는 IVI 케이스 스터디의 차이와 확인된 연구 콘텐츠를 기록한다.

## 구현과 수정 위치

- 진입: 메인 프로젝트 카드 → `/work/ivi/`. `/work/ivi`도 로컬 서버에서 정상 경로로 이동한다.
- 편집 원본: `portfolio-shell/dist/work/ivi/index.html`, `style.css`, `script.js`, `assets/`. 기존 빌드는 이 경로를 보존한다.
- 각 장의 `id`와 `data-chapter`는 유지한다. 목차 링크와 한 장 단위 수정에 사용한다.
- 00 cover / 01 background / 02 question / 03 layouts / 04 tasks / 05 method / 06 findings / 07 direction / 08 reflection.
- 메인 쉘 스타일과 타 프로젝트는 변경하지 않는다. 메인 IVI 표지는 기존 자산 유지.

## 표현 방향

화이트 #FFFFFF, 보조 #F5F5F5, 차콜 #171A20, 포인트 #D71920. Pretendard, 큰 이미지와 짧은 메시지, 여백과 얇은 선 중심. 테슬라의 미니멀한 방향을 참고한 자체 규칙이며 공식 테슬라 디자인 시스템이 아니다.
결과는 0–30초 동일 축의 과제 전환형 막대그래프로 비교한다. 데이터 테이블은 펼쳐볼 수 있다. 색 외에도 최단 표시와 실제 숫자를 제공한다. 조합 배치는 연구 기반 제안으로 분리한다.

## 원자료와 사실

사용자 제공 「IVI 메뉴 레이아웃이 운전자 성능 및 주관적 작업부하에 미치는 영향에 대한 연구_김성원 (1).pdf」, 총 34쪽. 2026-10-19 확인.
- 15개 인터페이스 조사 → 통합·더블 탭·상단·측면 메뉴형.
- 참가자 15명, 20~30대, 운전 경력 1년 이상. 약 40분.
- BeamNG.drive, 레이싱 휠/페달, 터치스크린 노트북, Figma/Maze.
- 공조 조절, 앱 배치 변경, 연락처 전화 걸기. 주행 정보 과제는 최종 분석 제외.
- 레이아웃과 과제 무작위 제시. 과제 정독 후 30초 주행하고 과제 시작.
- 수행시간·클릭 수·클릭 오류율·클릭 히트맵, NASA-TLX 기반 7점 평가, 만족도 5점 평가.

| 과제 | 통합 DT | 더블 탭 DT | 상단 DT | 측면 DT |
|---|---:|---:|---:|---:|
| 공조 |15.15|19.14|22.32|17.96|
| 메뉴 |22.15|24.74|28.71|19.49|
| 전화 |15.35|20.14|16.05|13.87|

단위 초, n=15. pp.17–19의 평균. p.20 보고 ANOVA는 공조 DT p=.018, 메뉴 DT p=.016/TC p<.001/MR p=.001, 인포 DT p=.042. 공조/인포 TC·MR은 유의하지 않음.
사후검정에서 차이가 확인된 수행시간 쌍: 공조 통합↔상단, 메뉴 측면↔상단, 인포 측면↔더블 탭. 모든 쌍의 차이를 주장하지 않는다.
p.26 정신적 요구도 측면 2.80/상단 5.27, p.27 조작 용이성 측면 4.40/상단 2.87. 이 개별 항목은 평균 비교이며 쌍별 유의성 주장 금지.
시선 추적/사고율/안전 기준 충족을 직접 검증한 결과로 쓰지 않는다. 하이브리드 제안은 미검증.

## 자산

- `assets/hero.webp`: 사용자 요청으로 생성한 차량 실내/터치 손 목업. 빈 화면이며 UI 합성 예정임을 캡션에 명시.
- `assets/research-landscape.webp`: 발표자료 p.7 조사 그림 크롭.
- `assets/experiment.webp`: p.11 실제 실험 사진 크롭.
- `assets/task-menu.webp`: p.13 실제 프로토타입 화면 크롭.
- CSS 레이아웃 그림은 설명용 구조도이며 실험 화면으로 표시하지 않는다.

## 남은 콘텐츠

개인 기여 범위, 정확한 수행 기간, 최종 표지 UI 합성은 미확정. 임의 수치·역할을 생성하지 않는다. 사용자가 각 장을 순서대로 수정할 수 있도록 현재 내용은 초안으로 구성했다.

## 검증 (2026-10-19)

기존 build.cjs 실행, JS 구문 검사, 내부 링크/자산/섹션 ID 검사 완료. 미리보기는 bwrap proc 마운트 권한 오류로 기동 실패. 실제 데스크톱·태블릿·모바일 렌더링 및 키보드 상호작용은 미검증. CSS 반응형/포커스/동작 축소 규칙은 구현되어 있으나 실제 QA 통과로 해석하지 않는다.
